Connect both accounts

Dubdeck reads your playlists from Spotify and writes them to YouTube Music. Your logins stay in this browser. The Dubdeck server never stores them.

Spotify

Connected as

Spotify asks every tool like this to have its own developer app. Setting one up takes about two minutes.

  1. Open the Spotify developer dashboard and choose Create app. Any name and description will do.
  2. Under Redirect URIs, add
  3. Tick Web API, save, then copy the Client ID from the app's page.

Using the Client ID ending in .

Make sure is listed under Redirect URIs in that Spotify app.

Spotify only lets the app's owner and up to five people they add use a developer app, and the owner needs Premium. Only playlists you own or collaborate on can be read.

YouTube Music

Connected as

YouTube Music has no public sign-in for tools like this, so Dubdeck uses a copy of your browser's request headers instead.

  1. Open music.youtube.com in Chrome, Edge or Firefox and make sure you're signed in.
  2. Press F12, open the Network tab and type browse in its filter box.
  3. Click Library in YouTube Music so a browse request appears.
  4. Right-click the request and choose Copy, then Copy request headers. In Firefox, open its Headers panel, switch on Raw under Request Headers and copy everything.

These headers work like a password for your Google account. They're kept in this browser and sent only with Dubdeck's requests to YouTube Music. The server uses them for that request and doesn't keep them. Disconnect when you're done.

Choose playlists

Each one becomes a new playlist on YouTube Music. You'll check the matches before anything is created.

    Greyed-out playlists belong to someone else, and Spotify doesn't let apps read their songs. To bring one over, open it in Spotify, select all songs (Ctrl+A), add them to a new playlist of your own, then reload this list.

    Finding your songs on YouTube Music

    Each song is looked up by its recording code first, then by title, artist and length. Keep this tab open.
